# Multimedia Binaries

This folder can hold local copies of multimedia binaries:
- `ffmpeg.exe` / `ffmpeg`
- `ffprobe.exe` / `ffprobe`
- `yt-dlp.exe` / `yt-dlp`

> **Note:** Binary files larger than 100MB are excluded from Git per GitHub file limits.  
> The system automatically discovers `ffmpeg` and `ffprobe` from your system `PATH` (e.g. installed via winget `winget install Gyan.FFmpeg` or chocolatey `choco install ffmpeg-full`).
